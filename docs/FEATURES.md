# 📋 Функциональные возможности «коробка»

| Функция | Описание | Статус |
|---|---|---|
| Импорт файлов | Выбор изображений через системный диалог (мультивыбор) | ✅ Реализовано |
| Импорт папки | Рекурсивный обход каталога и импорт всех поддерживаемых файлов | ✅ Реализовано |
| Drag-and-drop | Перетаскивание файлов в окно; попадание в текущую папку | ✅ Реализовано |
| Прогресс импорта | Индикатор хода импорта и видимые сообщения об ошибках | ✅ Реализовано |
| Форматы | PNG, JPG, JPEG, WEBP, BMP, GIF, TIFF, SVG (превью), ICO | ✅ Реализовано |
| Метаданные | Размеры (ширина × высота), формат по сигнатуре файла, в фоне (изолят) | ✅ Реализовано |
| Палитра | Автоизвлечение доминирующих цветов | ✅ Реализовано |
| Папки | Создание / переименование / удаление, счётчики элементов | ✅ Реализовано |
| Перемещение | В папку через правую панель, контекстное меню или диалог | ✅ Реализовано |
| Теги | Добавление / удаление, фильтрация по тегу из левой панели | ✅ Реализовано |
| Избранное | Флаг и отдельный раздел | ✅ Реализовано |
| Корзина | Мягкое удаление, восстановление, удаление навсегда, очистка | ✅ Реализовано |
| Поиск | Полнотекстовый (название + заметки), регистронезависимый для кириллицы | ✅ Реализовано |
| Фильтр по цвету | Отбор по цветам палитры | ✅ Реализовано |
| Сортировка | Дата ↑/↓, название А-Я/Я-А, размер изображения | ✅ Реализовано |
| Режимы просмотра | Сетка / Masonry (waterfall) / Список + слайдер размера превью | ✅ Реализовано |
| Lightbox | Полноэкранный просмотр, зум (кнопки/колесо/жест), навигация стрелками, Esc | ✅ Реализовано |
| Контекстное меню | Открыть, избранное, переместить, удалить — по правой кнопке | ✅ Реализовано |
| Умные папки | Автогруппировки по формату / цвету / тегам | ✅ Реализовано |
| Экспорт | Выгрузка выбранного элемента или текущего списка в папку | ✅ Реализовано |
| Настройки | Корневой каталог коллекции, тема, режим просмотра, сортировка, зум | ✅ Реализовано |
| Горячие клавиши | G / M / L — режимы, T — тема, Delete — в корзину | ✅ Реализовано |
| Темы | Светлая / тёмная / системная с сохранением выбора | ✅ Реализовано |
| Дубликаты | Поиск копий по SHA-256 содержимого, группы с оригиналом, удаление лишних | ✅ Реализовано |
| Видео | mp4/mov/avi/mkv/webm и др.: плейсхолдеры, открытие системным плеером | ✅ Реализовано |
| Аудио + BPM | mp3/wav/flac/ogg и др.; поле BPM с автотегом «BPM <n>» для фильтрации | ✅ Реализовано |
| Копирование цвета | Клик по цвету палитры → HEX-код → копирование в буфер | ✅ Реализовано |
| Изменяемые панели | Перетаскивание границ панелей мышью с сохранением ширины | ✅ Реализовано |
| Локальный HTTP-сервер | Приём файлов от расширения браузера и сторонних приложений одним кликом (как Eagle Browser Extension). Запускается на `127.0.0.1`, порт настраивается, поддержка base64/data:URL/HTTP-URL и пакетной отправки. | ✅ Реализовано |
