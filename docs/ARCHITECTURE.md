# 🏗️ Архитектура приложения «коробка»

Десктопное приложение для Windows на Flutter, повторяющее функциональность Eagle.

---

## 1. Общая архитектура

Приложение построено на **трёхслойной архитектуре**:

```
┌─────────────────────────────────────────────┐
│            UI слой (Flutter widgets)         │
│  Сетки, панели, галереи, предпросмотр        │
├─────────────────────────────────────────────┤
│         Слой состояния (Provider)            │
│  Управление коллекцией, фильтрами, поиском   │
├─────────────────────────────────────────────┤
│           Данные и сервисы                   │
│  Файловая система, SQLite, метаданные        │
└─────────────────────────────────────────────┘
```

### Слои

| Слой | Ответственность | Ключевые пакеты |
|---|---|---|
| **UI** | Отображение интерфейса, взаимодействие с пользователем | `flutter/material` |
| **State** | Управление состоянием, бизнес-логика | `provider` |
| **Data** | Работа с файлами, БД, метаданными изображений | `sqflite`, `sqflite_common_ffi`, `path_provider`, `image`, `shared_preferences` |

## 2. Ключевые компоненты

### 2.1. Управление коллекцией (`lib/features/collection/`)
- **CollectionState** — состояние коллекции (выбранная папка, режим просмотра, поиск, фильтры, выбранный элемент)
- **CollectionService** — высокоуровневые операции (папки, элементы, избранное, теги, перемещение, поиск)
- **SmartFolderService** — умные папки (автоматическая группировка по правилам)

### 2.2. Работа с изображениями (`lib/features/images/`)
- **ImageService** — выбор файлов/папок, проверка форматов, копирование
- **MetadataService** — извлечение метаданных (размер, разрешение, формат)
- **PaletteService** — автоизвлечение цветовой палитры из изображения
- **ImportController** — управление процессами импорта (файлы/папка/drag-and-drop)
- **ExportService** — выгрузка элементов коллекции в папку на диске

### 2.3. Поиск и фильтрация (`lib/features/search/`)
- **SearchService** — полнотекстовый поиск и фильтры (теги, формат, дата, цвет, избранное)

### 2.4. Настройки (`lib/features/settings/`)
- **ThemeProvider** — управление темой (светлая/тёмная/системная) с сохранением выбора

### 2.5. Хранилище данных (`lib/data/`)
- **AppDatabase** — инициализация SQLite (`sqflite_common_ffi` для десктопа)
- **DAOs** — объекты доступа к данным (FolderDao, ItemDao, TagDao)
- **Модели** — Folder, CollectionItem, Tag, SmartFolder
- **SettingsRepository** — сохранение настроек через `shared_preferences`

### 2.6. Интерфейс (`lib/widgets/` и `lib/screens/`)
- **MainScreen** — главный экран (компоновка панелей + горячие клавиши)
- **LeftPanel** — навигация (системные разделы, папки, умные папки)
- **ContentArea** — сетка/список элементов, панель инструментов (поиск, фильтры, импорт, экспорт)
- **RightPanel** — детали выбранного элемента (метаданные, теги, аннотации, перемещение)
- **LightboxViewer** — полноэкранный просмотр с зумом и навигацией
- **DropZone** — drag-and-drop файлов в окно

## 3. Схема базы данных (SQLite)

```
┌─────────────┐     ┌──────────────────┐
│   folders   │     │      items       │
├─────────────┤     ├──────────────────┤
│ id          │     │ id               │
│ name        │     │ folder_id  ──────┼──► folders.id
│ parent_id ──┼──►  │ title            │
│ created_at  │     │ path             │
└─────────────┘     │ width            │
                    │ height           │
┌─────────────┐     │ format           │
│    tags     │     │ palette          │
├─────────────┤     │ notes            │
│ id          │     │ is_favorite      │
│ name        │     │ created_at       │
└─────────────┘     └──────────────────┘

┌───────────────────┐
│   item_tags        │   (связь many-to-many)
├───────────────────┤
│ item_id ────────┼──┼──► items.id
│ tag_id  ────────┼──┼──► tags.id
└───────────────────┘
```

### Сущности
- **folders** — папки коллекции (иерархическая структура)
- **items** — элементы коллекции (изображения с метаданными, палитрой)
- **tags** — теги
- **item_tags** — связь элементов и тегов (many-to-many)

### Индексы
- `idx_items_folder` — по `folder_id` (быстрый отбор по папке)
- `idx_items_title` — по `title` (быстрый полнотекстовый поиск)

## 4. Потоки данных

### Импорт изображения
```
Пользователь (drag-and-drop / файл / папка)
        │
        ▼
    ImportController
        │
        ▼
    CollectionService.addItem()
        ├──► копирует файл в хранилище коллекции
        ├──► MetadataService: извлекает размер/разрешение/формат
        ├──► PaletteService: извлекает палитру
        ▼
    ItemDao.insert → AppDatabase
        ▼
    UI: обновляет сетку (CollectionState.refreshItems)
```

### Поиск и фильтрация
```
Ввод запроса / выбор фильтра
      │
      ▼
  CollectionState.setSearchQuery / setColorFilter
      │
      ▼
  SearchService.search → ItemDao.search (ItemFilter)
      │
      ├──► по названию/заметкам (LIKE)
      ├──► по тегам (JOIN item_tags)
      ├──► по формату, дате, избранному
      ├──► по цвету палитры (LIKE по JSON)
      ▼
  Результаты → UI-сетка
```

### Умные папки
```
Пользователь выбирает умную папку
      │
      ▼
  SmartFolderService.getItemsFor(SmartFolder)
      │
      ├──► по формату / цвету / тегам
      ▼
  Диалог с подходящими элементами
```

### Экспорт
```
Пользователь нажимает «Экспорт»
      │
      ▼
  CollectionState.exportSelectedItem / exportCurrentItems
      │
      ▼
  ExportService.exportItems
      ├──► выбор целевой папки (file_picker)
      ├──► копирование файлов с уникальными именами
      ▼
  Результат → SnackBar (экспортировано / ошибок)
```

## 5. Хранение данных

- **Изображения** хранятся в корневом каталоге коллекции (настраивается пользователем, по умолчанию — каталог поддержки приложения)
- **Метаданные** — в SQLite базе (`korobka.db`)
- **Настройки интерфейса** (тема, режим просмотра, корневой каталог) — в `shared_preferences`

```
Корневой каталог коллекции/
├── .korobka/
│   ├── korobka.db        # БД метаданных
│   └── settings.json     # настройки (shared_preferences)
└── images/               # файлы изображений
    ├── 2026/08/17/
    │   └── 172_...png
    └── ...
```

## 6. Поддерживаемые форматы изображений

| Тип | Расширения |
|---|---|
| Растровые | PNG, JPG, JPEG, WEBP, BMP, GIF |
| Дополнительно | TIFF, SVG (превью), ICO |

> Метаданные и палитра извлекаются для растровых форматов.

## 7. Принципы разработки

- **Чистая архитектура** — разделение UI / логики / данных
- **Provider** — минимальное, но масштабируемое управление состоянием
- **Модульность** — каждая фича в собственной папке `features/`
- **Тестируемость** — сервисы изолированы и покрываются unit-тестами
- **Горячие клавиши** — `CallbackShortcuts` для быстрого управления
- **Гибкость** — умные папки и фильтры легко расширяются новыми правилами
