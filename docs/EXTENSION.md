# Расширение браузера «Коробка» (v0.5.0)

Расширение позволяет сохранять картинки с любых сайтов прямо в коллекцию
приложения «Коробка» — как расширение Eagle.

## Что нового в v0.5.0 (объединение v0.4 + v4.1.0)

| Что | Как работает |
|---|---|
| Окно выбора папки в дизайне v4.1.0 | Окно из скриншота (слева «Перетащите файлы сюда», справа папки, внизу «Создать или выбрать папку») теперь встроено прямо в страницу и совмещено с функционалом v0.4: папки приложения подгружаются и синхронизируются каждые 3 с, кнопка «Создать или выбрать папку» реально создаёт папку, бросок файла в зону сохраняет его в выбранную папку |
| Настройка «Спрашивать папку для сохранения» | Хранится глобально (chrome.storage.local): включается один раз в настройках, действует сразу на всех сайтах и НЕ сбрасывается при переходе на новую страницу, после её перезагрузки и после перезапуска браузера. Пока включена — каждое сохранение сначала открывает окно с папками, и картинка уходит в ту папку, на которую вы кликнули (создание папки тоже сразу сохраняет в неё) |
| Файлы из Проводника | Отдельное небольшое окно по-прежнему принимает файлы из Проводника (в том числе в режиме «Спрашивать папку» — клик по папке сохраняет) |
| Явный выбор корня | Клик «Все картинки (корень)» сохраняет именно в корень, а не в последнюю папку |

## Что исправлено в v0.4.0 (по отзыву пользователя)

| Проблема | Причина | Исправление |
|---|---|---|
| Перетаскивание картинки со страницы — картинка не появляется в приложении | В приложении не было API-команды приёма картинок, расширение получало 404 | Добавлены `POST /api/item/add` (url/base64) в приложение и надёжная отправка в расширении |
| Кнопки «Создать»/«Выбрать папку» ничего не делают | Не было `POST /api/folder/create`, клики уходили в 404 | Кнопка «Создать» работает, выбор папки сохраняется |
| В поле «нет папок» не видно папок из приложения | Список не загружался/не обновлялся | Список папок загружается из приложения и **обновляется каждые 3 секунды**, пока открыто окно расширения |
| Ошибка в настройках плагина | Страница настроек падала на неинициализированных значениях | Настройки переписаны: все значения с запасными значениями по умолчанию, ошибки соединения показываются текстом |
| На Pinterest браузер показывал запрос «доступ к приложениям и сервисам на этом устройстве» | Старое расширение отправляло запросы к 127.0.0.1 прямо со страницы сайта — Chrome требует для этого отдельное разрешение (Private Network Access) | Теперь все запросы к приложению идут через сервис-воркер расширения, а не со страницы — запрос больше не появляется, можно смело нажимать «Блокировать», если он возник от старой версии |
| В окне перетаскивания не было папок приложения и кнопка «Создать или выбрать папку» не работала | Окно не получало данные из приложения | Воссоздано окно перетаскивания (как в Eagle): слева зона броска, справа список папок приложения с автосинхронизацией и рабочей кнопкой создания папки |
| Pinterest | Превью фиксированного размера | Ссылка автоматически повышается до оригинала (`/originals/`), если недоступно — перебор 736x/564x |

## Установка

1. Соберите и запустите приложение «Коробка» (v0.4.0+): `flutter build windows --release`.
2. Откройте Chrome → `chrome://extensions`.
3. Включите «Режим разработчика» (переключатель справа сверху).
4. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/`
   (или распакованный архив `korobka-extension-v0.5.zip`).
   Старые версии (v0.4 и v4.1.0) удалите — новая заменяет их обе.
5. Закрепите иконку «Коробка» на панели.

## Как сохранять картинки

1. **Перетаскивание с окном (как в Eagle / как в v4.1.0).** Потяните картинку
   по странице — откроется окно с папками: слева зона броска, справа папки
   приложения. Бросьте картинку в зону — она сохранится в выбранную папку.
   Если включено «Спрашивать папку» — бросьте картинку куда угодно,
   затем кликните нужную папку справа: клик = сохранить в неё.
2. **Перетаскивание по странице.** Отпустите картинку прямо на странице —
   она улетит в выбранную папку без окна (или через окно, если включено
   «Спрашивать папку»).
3. **Контекстное меню.** Правый клик по картинке → «Сохранить картинку в Коробку»
   (при включённом «Спрашивать папку» — сначала откроется окно с папками).
4. **Всплывающее окно.** Выберите папку (список синхронизируется с приложением),
   при необходимости создайте новую кнопкой «Создать», затем нажмите
   «Сохранить картинку со страницы» — расширение возьмёт самую большую
   картинку на странице.

## Окно выбора папки (в странице, дизайн v4.1.0)

- Открывается при перетаскивании картинки рядом с курсором; клик мимо окна,
  Escape или ✕ закрывают его.
- Папки в правой панели синхронизируются с приложением каждые 3 секунды.
- Кнопка «Создать или выбрать папку» создаёт папку прямо в приложении.
- Режим «Спрашивать папку»: брошенная картинка ждёт клика по папке —
  клик по папке (или создание новой) сохраняет её туда.
- Отключается в настройках («Показывать окно с папками при перетаскивании
  картинки»); режим «Спрашивать папку» включает его принудительно.

## Как работает синхронизация папок

- Список папок берётся из приложения по адресу `GET 127.0.0.1:41595/api/folder/list`
  (порты перебираются автоматически: 41595 → 41596 → 41597).
- Пока всплывающее окно открыто, список обновляется каждые 3 секунды:
  папка, созданная в приложении, появляется в расширении сама.
- Кнопка «Создать» отправляет `POST /api/folder/create` — папка сразу
  появляется и в приложении (обновление UI мгновенное).

## Если приложение закрыто

Расширение не теряет картинки: они сохраняются через браузер в
«Загрузки/Коробка» (горячая папка). Приложение заберёт их в коллекцию
при следующем запуске. Поведение настраивается на странице настроек
(вариант «Только в приложение» отключает запасной путь).

## Файлы расширения

```
extension/
├── manifest.json      — манифест MV3
├── background.js      — сервис-воркер: поиск приложения, API, окно приёма
│                        файлов из Проводника, запасная загрузка в горячую папку
├── content.js         — перехват перетаскивания, окно выбора папки в странице
│                        (дизайн v4.1.0), режим «Спрашивать папку»
├── drag.html/css/js   — отдельное окно приёма файлов из Проводника
├── overlay.css        — стили баннера и подтверждений
├── popup.html/css/js  — всплывающее окно (папки, создание, сохранение)
├── options.html/css/js— настройки (в т.ч. «Спрашивать папку для сохранения»)
└── icons/             — иконки 16/32/48/128
```
