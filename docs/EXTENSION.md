# Расширение браузера «Коробка» (v0.6.0)

Расширение позволяет сохранять картинки с любых сайтов прямо в коллекцию
приложения «Коробка» — как официальное расширение Eagle.

**v0.5.0 — настоящее объединение v0.4 и v4.1.0.** За основу взят полный
пакет v4.1.0 (дизайн попапа, окна выбора папки, пакетного сохранения и
всех окон не изменился), а в него встроен работавший в v0.4 функционал
связи с приложением: поиск сервера на портах 41595–41597, список папок
с автосинхронизацией, создание папок, прямое сохранение в коллекцию
(`POST /api/item/add`), Pinterest-оригиналы и запасная горячая папка.

## Что нового в v0.6.0

| Что | Как работает |
|---|---|
| Кнопка «Создать папку» в окне выбора папки | Постоянная кнопка рядом с поиском — не нужно набирать имя в поиске, чтобы увидеть пункт «Создать …». Папка создаётся в приложении (`POST /api/folder/create`) и сразу используется для сохранения |
| Комментарий сохраняется в приложении | Поле «Добавить комментарий» в окне выбора папки больше не теряется: текст передаётся в `POST /api/item/add` (annotation) и попадает в поле «Комментарий» элемента. Тоже верно для тегов и названия (требуется приложение 0.5.0+) |
| Живая синхронизация папок | Пока окно выбора папки открыто, список папок перечитывается из приложения каждые 3 секунды: если приложение запустили позже или добавили папку — список обновится сам |
| Понятный статус | Если приложение не запущено/устарело/без папок — под поиском появляется подсказка, а не пустой список |
| Надёжность | Запросы списка папок и создания папки ограничены таймаутами — зависший сервис-воркер больше не оставляет список пустым навсегда; при устаревшем приложении сообщения прямо говорят об этом |

| Что | Как работает |

| «Создать или выбрать папку» в панели перетаскивания | Бросок на этот пункт открывает то же окно выбора папки — даже если переключатель выключен |

| Приложение закрыто | Запасной путь не потерялся: файл уходит в «Загрузки/Коробка[/Папка]» через браузер и импортируется при запуске приложения |

## Установка

1. Соберите и запустите приложение «Коробка» (v0.5.0+): `flutter build windows --release`.
2. Удалите из браузера старые версии расширения (v0.4 и v4.1.0) — они конфликтуют.
3. Откройте Chrome → `chrome://extensions`, включите «Режим разработчика».
4. «Загрузить распакованное расширение» → папка `extension/` из репозитория
   или распакованный `korobka-extension-v0.6.zip`.
5. Закрепите иконку «Коробка» на панели.

## Как сохранять картинки

1. **Перетаскивание (дизайн v4.1.0).** Потяните картинку по странице — рядом
   с курсором появится панель с папками приложения и пунктом «Перетащите
   файлы сюда». Бросок на папку — сохранение в неё; бросок в зону слева —
   в корень коллекции; «Создать или выбрать папку» — открытие окна выбора.
2. **Окно выбора папки.** Открывается всегда, если включён переключатель
   «Спрашивать папку при сохранении» (на всех сайтах, пока не выключите),
   и по явному выбору «Создать или выбрать папку». Внутри — поиск по папкам,
   недавние, создание новой папки, теги и комментарий.
3. **Контекстное меню.** Правый клик по картинке → «Сохранить в Коробку».
4. **Попап.** Кнопки «Сохранить ссылку», «Сохранить группой» (окно пакетного
   сохранения с выбором папки), скриншоты области/видимой части/страницы.
5. **Горячие клавиши v4.1.0** работают как раньше (Alt+0…Alt+4, настраиваются).

## Как это устроено

- **Поиск приложения.** Сервис-воркер пингует `127.0.0.1:41595/41596/41597`
  (`GET /api/ping`, ответ `name:"korobka"`), найденный порт кэшируется на 3 с.
- **Список папок.** `GET /api/folder/list` выполняется только в сервис-воркере
  (контент-скрипты получают данные через `chrome.runtime.sendMessage` —
  никаких запросов со страницы сайта и связанных с этим предупреждений Chrome).
- **Создание папки.** `POST /api/folder/create {name, parentId}`.
- **Сохранение.** `POST /api/item/add {url | base64+mime+filename, folderId, annotation?, title?, tags?}`.
  Для URL сначала пробуется исходная ссылка, затем Pinterest-варианты
  (`/originals/` → `/736x/` → `/564x/`); для скриншотов и blob-картинок
  передаётся base64.
- **Запасной путь.** Если приложение не отвечает — файл сохраняется через
  `chrome.downloads` в «Загрузки/Коробка[/ИмяПапки]» и импортируется при
  следующем запуске приложения.
- **Журнал.** События сохранения пишутся в общий журнал приложения
  (`POST /api/log`, пакетная отправка раз в 2 с).
- **Переключатель «Спрашивать папку».** Ключ `usingCollect` в
  `chrome.storage.sync`. Исправлена причина «слётания» из v4.1.0: значение
  больше не перезаписывается пустыми данными приложения при каждой загрузке
  страницы.

## Файлы расширения

```
extension/
├── manifest.json            — манифест MV3, версия 0.6.0
├── js/background-v3.js      — сервис-воркер (точка входа)
├── js/lib/api/saver.js      — сохранение: приложение → горячая папка
├── js/lib/api/folder.js     — папки приложения (список, создание, кэш)
├── js/lib/api/item.js       — единая точка сохранения для всех окон
├── js/lib/api/preference.js — настройки (usingCollect без сброса)
├── js/lib/api/env.js        — shouldShowNewCollectWindow (окно выбора папки)
├── js/content.js            — перетаскивание, контекстное меню, скриншоты
├── js/lib/drag-saver.js     — панель перетаскивания v4.1.0
├── collect-window/          — окно выбора папки (дизайн v4.1.0)
├── batch-saver-window/      — окно пакетного сохранения (дизайн v4.1.0)
├── popup/                   — попап (дизайн v4.1.0, настройки на русском)
├── plugins/                 — сайт-плагины v4.1.0 (Pinterest, Twitter, …)
└── locales/                 — локализации (ru, en, …)
```
