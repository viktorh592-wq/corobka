# 🤖 CI/CD среда проекта «коробка»

Документ описывает настроенную систему непрерывной интеграции (CI) и непрерывной доставки (CD) для проекта.

---

## 1. Обзор

Конфигурация хранится в файле [`.sourcecraft/ci.yaml`](../.sourcecraft/ci.yaml) и использует встроенный механизм CI/CD платформы SourceCraft.

**Цель:** при каждом изменении кода автоматически проверять его качество и собирать Windows-версию приложения.

---

## 2. Триггеры запуска

CI/CD запускается автоматически при следующих событиях:

| Событие | Описание |
|---|---|
| `push` в ветку `main` | Проверка и сборка при каждом коммите |
| `pull_request` → `main` | Проверка изменений до слияния |

---

## 3. Рабочий процесс

Единый конвейер `analyze-test-build` выполняет следующие шаги:

```
push / pull_request
        │
        ▼
┌─────────────────────────────────────┐
│  Кубик 1: flutter-setup-analyze-test │
│  ├── flutter --version              │
│  ├── flutter pub get                │
│  ├── flutter analyze                │  ← статический анализ
│  └── flutter test                   │  ← автотесты
└─────────────────────────────────────┘
        │
        ▼
┌─────────────────────────────────────┐
│  Кубик 2: build-windows             │
│  └── flutter build windows --release│  ← сборка release
└─────────────────────────────────────┘
        │
        ▼
          Успех / Ошибка
```

### Шаги подробно

| Шаг | Команда | Назначение |
|---|---|---|
| Версия | `flutter --version` | Проверка окружения и SDK |
| Зависимости | `flutter pub get` | Установка пакетов из `pubspec.yaml` |
| Анализ | `flutter analyze` | Статический анализ кода, поиск ошибок |
| Тесты | `flutter test` | Выполнение unit-тестов |
| Сборка | `flutter build windows --release` | Сборка исполняемого файла Windows |

---

## 4. Инфраструктура

- **Воркер:** облачный (serverless) воркер SourceCraft
- **Образ:** Docker-образ с Flutter SDK (`cr.yandex/sourcecraft/flutter:stable`)
- **Окружение:** Linux-контейнер с установленным Flutter

> ⚠️ **Важно:** сборка нативного Windows-приложения (`.exe`) внутри Linux-контейнера имеет ограничения. Flutter для Windows требует компилятора MSVC и Windows SDK. Для полноценной сборки `.exe` может потребоваться специальный воркер или настройка окружения.

### Альтернативы сборки Windows
Если сборка через Linux-контейнер не сработает:
1. Использование **GitHub Action** для сборки Windows внутри CI/CD SourceCraft (на Windows-воркере).
2. Запасной переход на **Electron** (собирается кросс-платформенно без нативных ограничений Windows).

## 5. Статусы выполнения

| Статус | Описание |
|---|---|
| ✅ Успех | Все шаги выполнены, приложение собрано |
| ❌ Ошибка | Один из шагов завершился с ошибкой |

Просмотр статусов и логов — в разделе **Автоматизации → CI/CD** репозитория.
