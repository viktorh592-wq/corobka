## Версия 0.2 — Исправления и паритет с Eagle ✅

### Критические исправления
- [x] **Инициализация БД на десктопе** — проверка `databaseFactory == null` всегда была ложной
      (геттер не может быть null, он бросает StateError), из-за чего FFI-фабрика никогда
      не устанавливалась и любая операция с БД падала. Работала только тема.
- [x] **sqlite3_flutter_libs** — добавлена зависимость, поставляющая sqlite3.dll
      в собранное Windows-приложение.
- [x] **Единый CollectionService** — импортёр использовал свой экземпляр сервиса без
      инициализированного корневого каталога и копировал файлы в случайное место.
- [x] **Самостирающиеся поля** — заметки/название сбрасывались при вводе
      (контроллеры пересоздавались в build, selectItem откатывал данные).
