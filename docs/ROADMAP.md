## Версия 0.3 — Дубликаты, видео/аудио, BPM и UX-полировка ✅
### Исправления по отзывам пользователей
- [x] **Теги в левой панели** — раздел «Теги» теперь перечитывает список прямо
      из БД при каждом раскрытии (защитный рефреш), ошибки добавления тега
      стали видимыми (SnackBar), у поля добавления появилась кнопка «✓» —
      тег можно добавить и мышью, без Enter.
- [x] **Регистронезависимые теги** — «Природа» и «природа» больше не
      дублируются: SQLite `COLLATE NOCASE` работает только с ASCII,
      поэтому сверка регистров выполняется в Dart (кириллица).
- [x] **Панели с изменяемой шириной** — границы левой и правой панелей
      перетаскиваются мышью (курсор ↔, зажать ЛКМ — потянуть), размеры
      сохраняются между запусками.
- [x] **Тулбар без переполнения** — при узком окне панель инструментов
      прокручивается горизонтально вместо падения вёрстки.
- [x] **Устойчивость темы** — панели не падают, если тема без расширения
      PanelColors (fallback-палитра).

### Новые функции
- [x] **Кликабельная палитра** — клик по цвету под картинкой показывает
      HEX-код (#RRGGBB) с кнопкой копирования в буфер обмена; подсказка
      кода при наведении.
- [x] **Поиск дубликатов** — SHA-256 хэш содержимого считается при импорте
      (в изоляте); кнопка «Найти дубликаты» показывает группы копий с
      пометкой оригинала и перемещением лишних в корзину. Для старых
      элементов хэши досчитываются автоматически.
- [x] **Видео** — форматы mp4/mov/avi/mkv/webm/m4v/wmv/flv; иконки-плейсхолдеры
      в сетке и правой панели, открытие системным плеером (двойной клик или
      кнопка).
- [x] **Аудио и BPM-теги** — форматы mp3/wav/flac/ogg/m4a/aac/wma/opus;
      поле BPM у аудио сохраняет значение и автоматически ведёт тег
      «BPM <n>» (по нему работает фильтрация); смена/сброс BPM обновляет тег.
- [x] **Счётчики тегов** — у каждого тега в левой панели количество
      связанных элементов.

## Версия 0.3.1 — Локальный HTTP-сервер (прямой приём файлов) ✅

### Новые функции
- [x] **Локальный HTTP-сервер** — запускается на `127.0.0.1` (только локальная
      машина, извне недоступен), по умолчанию на порту `57323` (как Eagle).
      Принимает JSON-запросы на добавление файлов в коллекцию из расширений
      браузера и сторонних приложений — без ручного импорта.
- [x] **Протокол в стиле Eagle API**:
      * `GET  /api/health`         — статус сервера и приложения
      * `GET  /api/folders`        — список папок коллекции
      * `POST /api/folder/add`     — создать новую папку
      * `POST /api/item/add`       — добавить один элемент (base64, data:URL или HTTP-URL)
      * `POST /api/items/add`      — пакетный импорт нескольких элементов
- [x] **Теги и папки** — при отправке элемента можно указать `folderId` и
      массив `tags`; теги создаются автоматически, если их ещё нет.
- [x] **CORS** — ответы содержат `Access-Control-Allow-Origin: *`, чтобы
      запросы работали прямо из расширений браузера без прокси.
- [x] **Настройки** — тумблер включения/выключения и поле ввода порта в
      диалоге настроек, состояние сохраняется между запусками. В AppBar
      добавлен индикатор статуса сервера.
- [x] **Тесты** — 11 тестов на эндпоинты сервера (health, folders, item/add,
      пакет, data:URL, теги, папки, ошибки, CORS preflight, 404).

**Результат:** внешние приложения могут отправлять файлы в «Коробку» одним
кликом, без ручного импорта. Описание API — в
[docs/LOCAL_HTTP_API.md](LOCAL_HTTP_API.md).
