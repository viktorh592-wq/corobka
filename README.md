## ✨ Возможности (обзор)

Приложение повторяет ключевой функционал Eagle и находится в стадии активной разработки. Реализовано:

- 📥 **Сбор скриншотов** — импорт файлов, папок, drag-and-drop
- 📁 **Организация** — папки (создание/переименование/удаление), теги, избранное
- 🏷️ **Метаданные** — названия, заметки, автоизвлечение цветовой палитры и размеров
- 🔍 **Поиск и фильтры** — полнотекстовый поиск, фильтры по избранному/формату
- 🖼️ **Просмотр** — сетка, список, полноэкранный lightbox с зумом
- 🎨 **Темы** — тёмная и светлая (с сохранением выбора)
- ⌨️ **Горячие клавиши** — G (сетка), L (список), T (тема)

> 🔜 **В перспективе:** фильтр по цвету, умные папки, экспорт.

Подробнее — в [docs/FEATURES.md](docs/FEATURES.md) и [docs/ROADMAP.md](docs/ROADMAP.md).
