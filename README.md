## ✨ Возможности

Приложение повторяет ключевой функционал Eagle. Реализовано:

- 📥 **Сбор изображений** — импорт файлов, папок (рекурсивно), drag-and-drop в окно
- 📁 **Организация** — папки (создание/переименование/удаление, счётчики), теги, избранное
- 🗑️ **Корзина** — удаление обратимо, восстановление, очистка (как в Eagle)
- 🏷️ **Метаданные** — названия, заметки, автоизвлечение цветовой палитры и размеров
- 🔍 **Поиск и фильтры** — полнотекстовый поиск, фильтры по тегу/цвету палитры/избранному/формату
- ↕️ **Сортировка** — по дате, названию, размеру изображения
- 🖼️ **Просмотр** — сетка, masonry (waterfall), список; слайдер размера превью; полноэкранный lightbox с зумом
- ⚙️ **Настройки** — выбор корневого каталога коллекции, светлая/тёмная тема (с сохранением)
- 🖱️ **Контекстное меню** карточек — открыть, избранное, переместить в папку, удалить
- ⌨️ **Горячие клавиши** — G (сетка), M (masonry), L (список), T (тема), Delete (в корзину)

Подробнее — в [docs/FEATURES.md](docs/FEATURES.md) и [docs/ROADMAP.md](docs/ROADMAP.md).
