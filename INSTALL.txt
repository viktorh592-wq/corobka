ПАТЧ ПРИЛОЖЕНИЯ «КОРОБКА» — горячая папка «Загрузки/Коробка»
=============================================================

Основа: ветка main репозитория viktorh592-wq/corobka.
НЕ применяйте поверх ветки feature/local-http-server — серверная
схема заменена горячей папкой. Если у вас чекаутена она — сначала
git checkout main.

УСТАНОВКА (2 минуты)
--------------------
1. Откройте корень Flutter-проекта Коробки — папку, где лежат
   pubspec.yaml и папка lib/.
2. Распакуйте этот архив прямо туда (рядом с pubspec.yaml).
   Встанут ровно три файла:

   lib/main.dart                                  -> замена
   lib/features/collection/collection_state.dart  -> замена
   lib/features/import/hot_folder_service.dart    -> НОВЫЙ файл

   Если ваши main.dart / collection_state.dart уже отличаются от
   репозитория — не копируйте целиком, перенесите правки руками:

   * main.dart — две правки:
     1) импорт:  import 'features/import/hot_folder_service.dart';
     2) в build() KorobkaApp, в addPostFrameCallback после
        initialize():  await HotFolderService.startFor(
        context.read<CollectionState>());
        (готовый код — в lib/main.dart этого архива)

   * collection_state.dart — одна правка:
     добавить метод importExternalFiles(...) перед importDirectory()
     (готовый код — в файле из архива, метод с комментарием
     «/// Импорт файлов, пойманных папкой-приёмником…»)

3. Сборка:
   flutter pub get
   flutter run                            # проверка
   flutter build windows --release        # релиз

НОВЫЕ ЗАВИСИМОСТИ В pubspec.yaml НЕ НУЖНЫ — используются
path_provider (уже подключён) и dart:io.

ПРОВЕРКА
--------
1. Сохраните картинку расширением на любом сайте.
2. Файл появится в «Загрузки/Коробка», через 1–3 секунды —
   в коллекции Коробки (исходник из папки удаляется).
3. Подпапка «Загрузки/Коробка/Имя» = папка коллекции «Имя»
   (создаётся автоматически). Корень «Коробка» — общий список.
4. Закройте Коробку, сохраните 3 картинки, запустите снова —
   всё накопленное импортируется при старте.
